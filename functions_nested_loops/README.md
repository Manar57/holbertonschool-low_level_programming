# 0x02. C - Functions, Nested Loops

This project introduces functions and nested loops in the C programming language.

## Learning Objectives

- Understand nested loops.
- Understand functions and how to use them.
- Learn function prototypes and declarations.
- Understand variable scope.
- Learn how to use header files.
