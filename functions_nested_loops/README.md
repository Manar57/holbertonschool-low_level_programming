## Tasks

### 0. `_putchar`
- Prints `_putchar` followed by a new line.
- Uses the `_putchar` function.

### 1. Alphabet
- Prints the lowercase English alphabet followed by a new line.
- Uses a `while` loop and the `char` data type.
- Uses `_putchar` only twice.

### 2. 10 x Alphabet
- Prints the lowercase English alphabet 10 times.
- Uses nested while loops.
- Uses two variables to control repetition and character iteration.
- Uses _putchar only twice.

### 3. islower
- Checks whether a character is lowercase.
- Returns 1 if the character is between 'a' and 'z'.
- Returns 0 otherwise.
