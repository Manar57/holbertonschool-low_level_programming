# More Functions and Nested Loops

## Tasks

### 0. isupper
- Implemented `_isupper(int c)`.
- Checks whether a character is uppercase.
- Returns 1 if the character is between A and Z, otherwise returns 0.

### 1. isdigit
- Implemented `_isdigit(int c)`.
- Checks whether a character is a digit (0-9).
- Returns 1 if digit, otherwise returns 0.

### 2. Collaboration is multiplication
- Implemented `mul(int a, int b)`.
- Multiplies two integers and returns the result.

### 3. The numbers speak for themselves
- Implemented `print_numbers(void)`.
- Prints numbers from 0 to 9 followed by a new line.
- Uses `_putchar` only twice in the code.
