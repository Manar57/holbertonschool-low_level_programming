# 0x0E. C - Function pointers

Exercises on function pointers in C.

| File | Description |
| --- | --- |
| `function_pointers.h` | Header with all prototypes |
| `0-print_name.c` | `print_name`: prints a name using a function pointer |
| `1-array_iterator.c` | `array_iterator`: runs a function on each array element |
| `2-int_index.c` | `int_index`: returns the index of the first matching element |
| `3-calc.h`, `3-op_functions.c`, `3-get_op_func.c`, `3-main.c` | `calc`: simple calculator using function pointers |
